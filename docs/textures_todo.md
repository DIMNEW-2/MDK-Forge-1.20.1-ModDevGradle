# Текстуры: статус и что можно улучшить

Все текстуры мода (**193 PNG**) созданы программно скриптом `tools/gen_textures.py` (Pillow, пиксель‑арт без внешних
ассетов), поэтому ни один файл не является заглушкой‑пустышкой: у каждого предмета/блока/сущности есть читаемое изображение.
Тем не менее это генеративный пиксель‑арт, и художественная доработка приветствуется. Ниже — полный перечень и пометки
«что бы улучшить».

Регенерация: `python3 tools/gen_textures.py --sheet` (контрольный лист `build/texture_sheet.png`).

## Предметы (`assets/rpgmod/textures/item/`, 16×16)

| Группа | Файлы | Статус | Что улучшить |
|---|---|---|---|
| Мечи | `sword_<tier>_rpg.png` ×7 | ✅ генеративный | более выразительные гарды по тирам, блики на руне |
| Булавы | `mace_<tier>_rpg.png` ×7 | ✅ | шипы навершия читаются слабо на 16 px |
| Копья | `spear_<tier>_rpg.png` ×7 | ✅ | обмотка древка |
| Луки | `bow_<tier>_rpg.png` + `_pulling_0..2` ×28 | ✅ | кадры натяжения упрощены (тетива + стрела линиями) |
| Арбалеты | `crossbow_<tier>_rpg.png` + `_pulling_0..2`, `_arrow`, `_firework` ×42 | ✅ | кадр `firework` отличается только цветом снаряда |
| Бомбы | `bomb_<type>.png` ×6 | ✅ | дымовая бомба — только серый шар |
| Стрелы / болты | `arrow_<effect>.png` ×7, `bolt_<effect>.png` ×6 | ✅ | эффекты различаются цветом наконечника/оперения |
| Посохи / свитки | `staff_<school>.png` ×4, `scroll_<school>.png` ×4 | ✅ | свиток — печать школы, можно добавить узор |
| Броня (иконки) | `<class>_<piece>.png` ×32 | ✅ | силуэты одинаковые для всех классов, различие — палитра и акцент |
| Прочее | `forging_template.png`, `mana_potion.png`, `relations_map.png`, `skill_book.png` | ✅ | — |

Тиры: `wood, stone, iron, gold, diamond, netherite, rune`; школы: `fire, frost, lightning, nature`;
классы: `warrior, mage, archer, crossbowman, rogue, druid, spearman, bomber`.

## Броня на модели игрока (`textures/models/armor/`)

`<class>_layer_1.png`, `<class>_layer_2.png` ×16 (64×32) — ✅ сгенерированы в ванильной UV‑разметке (голова, тело,
руки, ноги залиты цветом класса с тенями и акцентной полосой). **Самый грубый участок:** это однотонная «раскраска»
силуэта, без деталей (наплечники, ремни, капюшон мага и т.п.). Если будете рисовать вручную — начните отсюда.

## Чего нет и почему

* **Отдельных моделей/текстур для стрел по типам** — рендерер один (`RpgArrowRenderer`), текстура общая. Добавить просто:
  карта `ProjectileEffect → ResourceLocation` в рендерере + PNG на каждый эффект.
* **Анимированной крышки сундука** — блок использует статическую модель; `open` используется только логикой.
* **Собственных звуков (.ogg)** — все 22 события (`sounds.json`) ссылаются на ванильные события (`type: event`),
  собственные файлы не нужны. Субтитры есть в обоих языках.
